truediscount

Privacy policy

Last updated: 27 October 2026

truediscount does not collect, transmit or sell any data. There is no account, no analytics and no server.

  • Product name, product URL path, price and date are stored locally in your browser so the extension can compare prices over time. History is kept for 90 days.
  • Price alert targets and the list of sites where you hid the badge are stored locally. Alerts are local browser notifications.
  • The extension makes no network requests. No data leaves your device.
  • "Report a problem" only opens a GitHub issue form in a new tab, prefilled with the shop's domain, the extension version and what was detected. Nothing is sent unless you submit that form yourself.
  • Backup and CSV export create files on your own device only.
  • You can delete all stored data from the popup ("Clear all data") or by removing the extension.

The use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Questions: GitHub issues.
