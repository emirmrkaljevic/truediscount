# Where to report a fake discount

Official places in each EU country to report a misleading price or get free help. Back to the [guides index](README.md) or the [README](../../README.md). Web version: [report a fake discount](https://emirmrkaljevic.github.io/truediscount/guides/report-a-fake-discount.html).

## Before you report

- Take a dated screenshot showing the sale price, the crossed-out price, the 30-day lowest price line (or that it is missing) and the page address.
- Add earlier screenshots or a price history showing the lower price, if you have them.
- Note the shop name and the country it sells from. If the shop is in another EU country, the European Consumer Centre (ECC) in your own country helps for free.
